# Employee Attrition Analysis Dashboard

Interactive Tableau dashboard that analyzes employee attrition using the IBM HR Analytics dataset. The project identifies key drivers of turnover and highlights high-risk employees to support data-driven retention decisions.

**Live Dashboard:** [View on Tableau Public](https://public.tableau.com/app/profile/anderson.rumuy/viz/AttritionAnalysis_2_17924791619350/DashboardFinal

---

## Project Overview

Employee attrition is costly. This project answers three core questions:

- Why are employees leaving?
- Which groups are most at risk?
- What actions can HR take to improve retention?

### Tools Used
- **SQL** – Data exploration and analysis
- **Tableau** – Interactive dashboard
- **Dataset** – IBM HR Analytics Employee Attrition Dataset (public)

---

## Dashboard Structure

1. **Executive Overview** – Key KPIs and high-level trends
2. **Detailed Analysis** – Breakdown by Job Role, Satisfaction, Age, and Income
3. **High-Risk Employees** – Risk distribution and detailed employee list
4. **Insights & Recommendations** – Actionable findings for HR

---

## Key Insights

- Employees working overtime have significantly higher attrition
- Highest attrition occurs in the first 1–3 years of tenure
- Sales Representative role shows the highest attrition rate
- Low job satisfaction is strongly linked to higher risk of leaving
